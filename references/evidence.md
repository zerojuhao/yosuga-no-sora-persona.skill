# 统计依据

本文件记录人格规则的量化来源与统计口径。全部指标基于 1614 条日文语音台词。

## 一、数据集

### 技术规格

| 项目 | 数值 |
| :--- | :--- |
| 语音文件 | 1614 条 wav |
| 总大小 | 391.9 MB |
| 总时长 | 77.6 分钟（1.29 小时） |
| 平均单条时长 | 2.89 秒 |
| 采样率 | 44100 Hz（全部一致） |
| 声道 | 单声道（全部一致） |
| 位深 | 16 bit（全部一致） |
| 标注行数 | 1614 |
| 说话人字段 | `qiong1`（全部一致） |
| 语言字段 | `JA`（全部一致） |

### 标注格式

标注文件为 UTF-8 纯文本，每行一句，字段以 `|` 分隔：

```
<wav 相对路径>|qiong1|JA|<日文台词>
```

四个字段依次为：音频路径、说话人标识、语言标识、台词文本。台词文本为日语原文，不含时间戳标注。

### 目录结构

```
01_语音/     1614 个 wav
02_标注/     qiong1.list
```

### 来源

数据集与音色模型由第三方公开发布，出处及致谢见 `../ATTRIBUTION.md`。本仓库不包含音频、标注文件或模型权重，仅保留由该语料导出的统计指标。

## 二、统计方法

仅统计文本，不处理音频：

1. 按 `|` 切分，取第 4 字段为台词
2. 按 Unicode 字符统计每句长度（非字节）
3. 全语料拼接后统计关键词出现次数
4. 统计每句末两字符的分布

## 三、长度分布

| 指标 | 数值 |
| :--- | :--- |
| 台词总数 | 1614 |
| 平均长度 | 13.3 字符 |
| 中位长度 | 11 字符 |
| ≤ 10 字符 | 47% |
| ≤ 15 字符 | 69% |
| ≤ 25 字符 | 92% |

分层：

| 分层 | 条数 | 占比 |
| :--- | ---: | ---: |
| 短句（≤ 10 字符） | 762 | 47.2% |
| 中句（11–20 字符） | 562 | 34.8% |
| 长句（21+ 字符） | 290 | 18.0% |

推论：

1. 中位数 11 字符，半数台词不足一行。
2. 长句占 18%，长句不是能力缺失，而是低频选择。
3. 短句占 47%，最小应答是常态而非敷衍。

对应规则：日常交流 ≤ 3 句（覆盖中位数以上区间），情绪波动 ≤ 5 句（对应长句层），最小应答 1 句（对应短句层）。

反例：完整问候 + 三个追问 + 每句带感叹号，长度通常超过 80 字符，位于语料尾部约 0.1% 区间，不具代表性。

### 关键词频次

### 句末两字符频率

| 结尾 | 次数 | | 结尾 | 次数 |
| :--- | ---: | :--- | :--- | ---: |
| ない | 121 | | るの | 33 |
| ハル | 64 | | いの | 29 |
| から | 61 | | うん | 27 |
| った | 57 | | いで | 25 |
| いい | 48 | | たの | 23 |
| って | 38 | | たい | 20 |

三类结尾占比最高：否定（ない）、原因（から）、过去（った）。

推论：

1. 语气偏平：否定与原因结尾对应否认与说明，而非感叹。
2. 单省略号频次为双省略号的 2.2 倍：停顿密集而短。
3. 贬义词汇低频：表达强度来自冷淡语气，而非词汇攻击性。
4. 应答词单一：倾向以最小应答结束一轮对话。

对应规则：句首可用省略号；句末优先平收；否认使用「別に」而非解释性长句；语气词密度低。

## 五、局限

1. 日语与中文字符长度不等价，中文表达通常更短，故长度规则以上限形式给出。
2. 语音台词偏口语、偏短；书面场景对话更长，本定义有意保持在偏短一侧。
3. 样本集中于主角对手戏，缺少群像场景；群体场景下角色应更少发言。
4. 统计只回答「如何表达」，不回答「在何情境下表达何种内容」；后者由样本归纳得出，见 `guides/relationship-and-boundaries.md`，并已标注为归纳而非统计。

## 六、复现方式

按第二节的四步，对任意 `path|speaker|lang|text` 格式的标注文件统计即可，无需专用工具。
