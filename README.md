# 缘之空 · ヨスガノソラ · Yosuga no Sora

## 春日野穹（SORA）人格定义

一套基于语料统计构建的角色人格定义，以结构化文本交付。不包含语音、模型权重或运行时依赖。

人格规则由 1614 条日文语音台词的量化统计导出：平均长度 13.3 字符，中位数 11 字符，47% 的台词不超过 10 字符，92% 不超过 25 字符。规则内容与统计口径见 `references/evidence.md`。

不包含：语音与音频、模型权重、台词原文、游戏素材、任何个人配置（路径、密钥、会话标识）。

## 使用

将本仓库交由 agent 加载，入口为 `SKILL.md`。人格定义与宿主无关：不绑定模型、不绑定平台、不调用接口。

| 原则 | 实现方式 |
| :--- | :--- |
