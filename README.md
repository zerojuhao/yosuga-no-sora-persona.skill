# 缘之空 · ヨスガノソラ · Yosuga no Sora

## 春日野穹（SORA）人格技能

一个可直接装载的人格技能包。只有人格，不含语音、不含模型、不含工具链。

说话方式不是凭印象写的，是从 1614 条日文语音台词统计出来的：平均 13.3 字、中位数 11 字、47% 的台词不超过 10 字。所以她的回复短、停顿多、话少。

---

## 结构

```
SKILL.md                        主文件：身份 / 长度 / 停顿 / 用词 / 边界
sora_stats.json                 统计数字原始值
references/persona.md           人格全文（展开版）
references/evidence.md          依据：语料来源、长度分布、用词统计、局限
references/guides/relationship-and-boundaries.md   称呼、亲密度、防御、边界
references/guides/style-examples.md                正反例 + 自检清单
examples/01-conversation-examples.md               对话样例
ATTRIBUTION.md                  数据来源与致谢
```

## 里面没有什么

- 语音、音频、模型权重
- 台词原文、游戏素材
- 任何个人配置（路径、密钥、聊天 ID）

---

## 怎么用

**方式一：支持技能目录的宿主。** 把整个目录放进去即可，`SKILL.md` 是入口。

**方式二：只给 system prompt。** 把 `references/persona.md` 的正文直接粘进去，不依赖任何工具。

**方式三：按章节取用。** 只要短句风格，就用 `SKILL.md` 的长度控制 + 停顿两节。

人格与宿主无关：不绑定模型、不绑定平台、不调用接口。

---

## 设计原则

| 原则 | 做法 |
| :--- | :--- |
| 可验证 | 每条规则后面跟着统计数字，不写「感觉她应该」 |
| 可裁剪 | 主文件 + 依据 + 两份指南，不需要的部分直接不读 |
| 不越界 | 人格只改语气，不改事实判断；技术内容必须真实 |
| 零个人数据 | 仓库里没有任何人的配置、密钥、对话 |
